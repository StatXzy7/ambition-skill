# 使用者语境（模板）

改写提示词时，用这里的信息填占位符。这是一份空白模板，请不要直接改它：把它复制到下面任一位置再填写，技能会优先读你的副本，升级技能时也不会被覆盖。

- `~/.claude/ambition/contexts.md`：对你所有的项目生效；
- 项目里的 `.claude/ambition/contexts.md`：只对这个项目生效，优先级更高。

填写时把 `{…}` 换成你自己的情况，用不上的小节直接删掉。没填的部分，技能会当它不存在，在改写后的提示词里留成 `{需要你填：…}`，不会去猜。

这里只记路径和规则，不记具体数字：数字会过期，用的时候到源文件里去读。

填好的样子见仓库里的 `examples/contexts.example.md`（虚构项目）。

下文的相对路径都以 `{你的工作根目录，例如 ~/work/}` 为根目录。最后核对：{日期}。

## 验证分级

选题和调研时，先判断一个方向的结果靠什么验证、多快能拿到反馈。下面是一个默认分法，可以按你的领域改。

| 层级 | 含义 | 典型手段 |
|---|---|---|
| L0 | 机器即时可验证（秒到分钟） | 形式证明、数值神谕逐位比对、对偶间隙或 KKT 证书、组合等价性检查、公开榜单自动评分、历史回测 |
| L1 | 靠科学计算验证（小时到天） | DFT、MD/FEP、CFD、蒙卡、长时间积分统计 |
| L2 | 靠训练出的代理模型，可信度有限 | 结构预测置信度（如 ipTM）、通用机器学习势、神经算子 |
| L3 | 必须做湿实验、用大装置或真实世界数据 | 合成与表征、结合实验、装置实验、现场实测 |

原则：L0 和 L1 的方向，AI 生成的东西直接有用；L2 和 L3 的方向，先搭代理验证器，校准后再用它的结论。

## 对外口径的通用规则

下面是一组默认规则，可以直接用，也可以按你的情况增删。

- **同口径**：同一台机器、同样的线程设置，两边在同一天交替测。
- **说清对照对象**：例如对照的是"用 Octave 运行的原版"，就不说"比 MATLAB 快"。
- **说清验证范围**：只在测试用例或合成数据上验证过，就要说出来。
- **不夸大一致性**："差在阈值以内"不写成"逐位一致"。
- **给出处**：每个数字都能追到某个文件、提交号或脚本。
- **页面是技术报告**：给合作方的材料里不写会议目标、请求和说服话术，这些留在内部的讲稿里；支线工作单独成册。
